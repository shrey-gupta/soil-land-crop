## Repository Notice

The **VITA-Plus** codebase is **not included** in this repository.

**VITA-Plus** is an extension of the original **VITA** framework, which is used in our work.  
The original **VITA** codebase is available at:  
https://github.com/Neehan/VITA

The corresponding **VITA** paper can be found here:  
https://arxiv.org/pdf/2508.03589

The **VITA-Plus** implementation is publicly available at:  
https://github.com/shrey-gupta/VITA-plus

## Notebook Overview

### `final-paper-forecasting-models.ipynb`
This notebook is the main experiment workflow used for final forecasting.  
It assembles feature pipelines, trains/evaluates model variants, and compares predictive performance across setups.

### `covariate-shift.ipynb`
This notebook analyzes source-vs-target distribution mismatch in weather and yield features.  
It includes covariate-shift diagnostics.
